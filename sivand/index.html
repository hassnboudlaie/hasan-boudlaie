اطلاعات پاسخ‌دهنده

پاسخ‌های واقعی را همراه منبع یا تاریخ وارد کنید. اگر داده‌ای در دسترس نیست، وضعیت «نامشخص» را انتخاب کنید. لازم نیست نسبت‌های محرمانه فرمولاسیون یا اطلاعات شخصی دیگران را وارد کنید.

اطلاعات صرفاً در همین مرورگر ذخیره می‌شود؛ هیچ پاسخی به GitHub یا سرور ارسال نمی‌شود. در پایان فایل خروجی را دانلود و برای مشاور ارسال کنید. برای ادامه در دستگاه دیگر، فایل پشتیبان JSON را وارد کنید.

دریافت و ارسال پاسخ‌ها

هر پرسشنامه جداگانه یا هر سه پرسشنامه را یکجا دریافت کنید. فایل JSON مناسب تحلیل و ورود مجدد است؛ گزارش HTML برای مشاهده و چاپ، و CSV برای بررسی جدولی.
