# R.F Gold — MVP Product Data

این پوشه ساختار اولیه دیتای محصول فروشگاه R.F Gold را نگه می‌دارد.

## منطق داده
هر محصول باید مستقل از ظاهر سایت، دارای شناسه، دسته، وزن، عیار، موجودی، مدل قیمت‌گذاری، وضعیت خرید آنلاین، خدمات پس از فروش و اطلاعات سئو باشد.

## تصمیم‌هایی که هنوز باید نهایی شوند
- مدل قیمت: ثابت / لحظه‌ای / تأیید پس از سفارش
- اجرت و سود: نمایش تفکیکی یا نهایی
- خرید آنلاین کامل یا رزرو + تأیید مشاور
- سیاست ارسال امن و احراز هویت
- ساختار کالکشن اختصاصی و Limited Edition
- سیاست باشگاه مشتریان و Early Access

فایل product-master-template.csv الگوی ورود تا ۲۰۰ محصول است.
