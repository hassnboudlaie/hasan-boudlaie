# صبا نفت | مهارت‌های رهبری مدیران

Public path: https://hassnboudlaie.github.io/hasan-boudlaie/sabanaft/

Six sessions, each with seven independently navigable sections and a responsive RTL sidebar. The current published Behparvar lab is the structural reference. Session one retains its original interactive self-assessments, dialogue feedback, ten-question quiz and handout, with independent Saba Naft data and adapted workplace examples. Sessions two to six contain original lessons, role-play, techniques, reflection, visuals and five-question quizzes for each session.

The two audience paths (managers/supervisors) have separate state. Notes are separated by session and section. Storage is browser-local and is not sent to the facilitator.

Storage keys:
- `sabanaft_session1_v4`: session one, audience state and original assessments.
- `sabanaft_session2_v1` through `sabanaft_session6_v1`: session-specific notes, separated by audience.
- `sabanaft_practice_v1`: additional-session practice answers and quiz submissions, separated by audience and session.

Company identity, source links and asset provenance are recorded in `sources.html` and `ASSETS.md`. Training cases are fictional. The official Farmanieh picture is a project architectural visualization; the Niayesh and meeting pictures are site photographs.

Buildless HTML, CSS and JavaScript. No server, account creation or analytics.

Validation: `node verify-session-core.js`, `node verify-session-dashboards.js`, `node verify-sabanaft.js`.
