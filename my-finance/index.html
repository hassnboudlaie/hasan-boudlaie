اطلاعات اختصاصی حساب شما

تصویر روی گوشی کوچک و به WebP تبدیل می‌شود. فایل در فضای خصوصی حساب شما ذخیره می‌شود؛ حداکثر ۶ مگابایت برای انتخاب.

اطلاعات این بخش برای کاربران دیگر قابل مشاهده نیست.

دستیار هوش مصنوعی شخصی · اختیاری

بدون اتصال پولی اجباری. استفاده عادی از My Finance مستقل از این بخش است.

این روش اتصال خودکار حساب ChatGPT نیست؛ اما می‌توانید از ChatGPT رایگان، لینک بازکردن پیش‌نمایش بسازید. هیچ رمز یا API Key لازم نیست.

روش سریع با یک لمس، بدون هزینه API

یک‌بار دستور زیر را در ChatGPT شخصی‌تان ارسال کنید. بعد برای هر هزینه، درآمد یا قرض پرداختی، با لمس لینک پاسخ، فرم بررسی My Finance باز می‌شود.

ثبت خودکار نیست؛ لینک فقط فرم قابل اصلاح را باز می‌کند و ثبت نیازمند تأیید شماست.

روش جایگزین: انتقال دستی متن و JSON

در ChatGPT خودتان پیام کپی‌شده را Paste و ارسال کنید. سپس فقط پاسخ JSON آن را کپی و اینجا وارد کنید. اطلاعات حساب‌ها و موجودی شما خودکار ارسال نمی‌شوند.

هیچ اطلاعاتی بدون تأیید شما در حساب مالی ثبت نمی‌شود.

اتصال مستقیم امن به سرویس AI شخصی در ارتقای آینده بررسی می‌شود؛ فعلاً ورود با حساب ChatGPT به معنی اتصال API نیست.

حریم خصوصی و داده‌ها

اطلاعات در این دستگاه ذخیره می‌شوند و پس از ورود امن، در فضای خصوصی Supabase همگام خواهند شد. داده‌های محلی رمزگذاری نشده‌اند؛ در دستگاه مشترک از آن استفاده نکنید. اطلاعات واقعی در GitHub ثبت نمی‌شوند.

فایل پشتیبان جدید با رمز مستقل (AES‑256‑GCM) محافظت می‌شود. رمز را فراموش نکنید؛ قابل بازیابی نیست. اطلاعات ذخیره‌شده داخل مرورگر هنوز رمزگذاری نشده‌اند.

ورود اطلاعات از ChatGPT پس از اتصال امن انجام می‌شود. پیش‌نویس‌های قدیمی همچنان قابل واردکردن هستند.
