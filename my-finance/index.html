Cloud Sync — Google Sheets خصوصی

رکوردهایی که با دستور شما در ChatGPT ثبت می‌شوند، پس از اتصال امن به حساب Google در اپ نمایش داده می‌شوند. این اتصال فعلاً برای «مطالبات» فقط خواندنی است.

اتصال ابری هنوز تنظیم نشده است.

برای راه‌اندازی یک‌باره، در Google Cloud یک OAuth Web Client بسازید؛ Google Sheets API را فعال کنید و همین دامنه GitHub Pages را در Authorized JavaScript Origins ثبت کنید. Access Token فقط در حافظه موقت صفحه می‌ماند.

حریم خصوصی و داده‌ها

اطلاعات در همین مرورگر ذخیره می‌شوند. GitHub Pages هیچ پایگاه داده مالی برای این برنامه ندارد. ذخیره‌سازی محلی به‌معنای رمزگذاری اطلاعات نیست؛ تا تکمیل امنیت، داده حساس وارد نکنید.
